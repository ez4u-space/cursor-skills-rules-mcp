# Гид по MCP-серверам Cursor

Этот файл — итог аудита и усиления MCP-серверов. Здесь два раздела:
1. Что было сделано с текущим `mcp.json` (что почищено, что починено, что добавлено).
2. Топовые MCP-серверы, которые требуют регистрации/OAuth — подключайте сами, когда будет 5-10 минут. Для каждого: что даёт, где взять доступ, готовый JSON-сниппет для `~/.cursor/mcp.json`.

---

## 1. Что было сделано с `~/.cursor/mcp.json`

### Удалено (не работало / устарело / небезопасно)

| Сервер | Причина удаления |
|---|---|
| `fetch` | Пакета `@modelcontextprotocol/server-fetch` **не существует** в npm. Официальный fetch-сервер — только на Python (`uvx mcp-server-fetch`), конфиг был скопирован из ошибочных статей в интернете. |
| `git` | Аналогично — официальный git-сервер тоже только на Python/`uvx`, а не npm-пакет. Плюс агент Cursor и так работает с git напрямую через терминал — отдельный MCP избыточен. |
| `postgres` | Официальный сервер архивирован в мае 2025, помечен deprecated в npm, содержит известную SQL-инъекцию в "read-only" защите. К тому же в конфиге была фейковая строка подключения — база не использовалась. |
| `sqlite` | Тоже архивирован и не поддерживается, путь к базе в конфиге не существовал. |

### Починено

| Сервер | Проблема | Решение |
|---|---|---|
| `filesystem` | Ошибка при запуске | Кэш `npx` (`%LOCALAPPDATA%\npm-cache\_npx`) был повреждён — в установленных пакетах отсутствовали файлы зависимости `zod`. Кэш очищен, пакет переустановлен с нуля. Плюс команда обёрнута в `cmd /c npx ...` — это стандартный фикс нестабильного спавна процессов на Windows в Cursor. |
| `sequential-thinking` | Та же ошибка | Та же причина и решение. |
| `memory`, `playwright` | Работали и без правок | Просто добавлена обёртка `cmd /c` для стабильности на будущее. |
| `github` | Устаревший npm-пакет `@modelcontextprotocol/server-github` (не поддерживается с апреля 2025) + токен лежал открытым текстом в файле | Перевёл на официальный поддерживаемый **remote-сервер** `https://api.githubcopilot.com/mcp/` с токеном через переменную окружения `${env:GITHUB_PAT}` — токен больше не хранится в файле. |

### ⚠️ ВАЖНО — нужно сделать руками

Старый GitHub-токен, который лежал в `mcp.json`, теперь считается скомпрометированным (он был виден в файле открытым текстом). Порядок действий:

1. Зайти на https://github.com/settings/tokens (вкладка уже открыта в браузере Cursor).
2. Найти старый токен и нажать **Revoke** (отозвать).
3. Создать новый токен: **Generate new token** → выбрать нужные права (обычно достаточно `repo`, `read:org`, `workflow`).
4. Скопировать новый токен и прописать его в переменную окружения Windows. В PowerShell:
   ```powershell
   setx GITHUB_PAT "ваш_новый_токен_сюда"
   ```
5. **Перезапустить Cursor полностью** (переменные окружения, заданные через `setx`, подхватываются только новыми процессами).
6. После перезапуска сервер `github` в списке MCP должен стать `ready`.

### Добавлено (не требует регистрации)

| Сервер | Что даёт |
|---|---|
| **Context7** (`https://mcp.context7.com/mcp`) | Актуальная, версионированная документация библиотек прямо в промпте агента — решает проблему "модель предлагает устаревший API". Работает без ключа, с ключом (context7.com/dashboard) — выше лимиты. |
| **Chrome DevTools MCP** (`chrome-devtools-mcp`) | Официальный сервер от команды Chrome: инспекция живой страницы, сетевые запросы, консоль, Lighthouse-аудиты, скриншоты — прямо из агента, без ручного открытия DevTools. |

### Итоговый рабочий набор

`filesystem`, `memory`, `sequential-thinking`, `playwright`, `context7`, `chrome-devtools` — все проверены и в статусе `ready`. `github` заработает после того, как вы зададите новый токен (см. выше).

## 2. Топовые MCP-серверы, требующие регистрации/OAuth

Ниже — проверенные, актуальные (2026) сервера. У каждого — пользa, ссылка и готовый JSON-сниппет. Просто скопируйте нужный блок внутрь `"mcpServers": { ... }` в `~/.cursor/mcp.json` и перезапустите Cursor.

### 🔎 Веб-поиск и скрапинг для агента

**Firecrawl** — скрапинг и кроулинг сайтов, отдаёт чистый markdown/JSON. Незаменим для research-задач и сбора данных с сайтов без ручного парсинга.
- Регистрация: https://firecrawl.dev → Dashboard → API Keys (бесплатный тариф есть)
```json
"firecrawl": {
  "command": "cmd",
  "args": ["/c", "npx", "-y", "firecrawl-mcp"],
  "env": { "FIRECRAWL_API_KEY": "fc-ваш_ключ" }
}
```

**Exa** — поисковик, спроектированный специально под ИИ-агентов, отдаёт очищенные релевантные результаты вместо сырой выдачи.
- Регистрация: https://exa.ai → Dashboard → API Keys (бесплатный тариф есть)
```json
"exa": {
  "command": "cmd",
  "args": ["/c", "npx", "-y", "exa-mcp-server"],
  "env": { "EXA_API_KEY": "ваш_ключ" }
}
```

**Tavily** — альтернатива Exa, оптимизирован под LLM-запросы, часто используется в паре с fetch-серверами.
- Регистрация: https://tavily.com → API Keys (бесплатный тариф есть)
```json
"tavily": {
  "command": "cmd",
  "args": ["/c", "npx", "-y", "tavily-mcp"],
  "env": { "TAVILY_API_KEY": "tvly-ваш_ключ" }
}
```

### 📋 Командная работа и таск-трекеры

**Notion** — заметки/вики. Официальный remote-сервер, OAuth прямо в браузере, никаких ключей руками копировать не нужно.
- Просто добавьте конфиг ниже, при первом обращении Cursor откроет браузер для входа в ваш Notion-аккаунт.
```json
"notion": { "url": "https://mcp.notion.com/mcp" }
```

**Linear** — таск-трекер для спринтов. Тоже официальный remote-сервер с OAuth.
```json
"linear": { "url": "https://mcp.linear.app/mcp" }
```

**Slack** — поиск по каналам, отправка сообщений. Официальный remote-сервер (нужно один раз подтвердить установку Slack-приложения в вашем воркспейсе).
- Инструкция: https://slack.com/help (раздел MCP/Apps) — Slack сам укажет URL для вашего воркспейса при подключении через Cursor Settings → MCP → Add.

**Atlassian (Jira + Confluence)** — тикеты, вики. Официальный remote-сервер с OAuth.
```json
"atlassian": { "url": "https://mcp.atlassian.com/v1/sse" }
```

### 🛠️ Инфраструктура и мониторинг

**Sentry** — мониторинг ошибок продакшена прямо из чата с агентом (посмотреть стектрейс, частоту, связать с кодом).
- Регистрация: https://sentry.io, затем Settings → MCP в Cursor, авторизация через OAuth.
```json
"sentry": { "url": "https://mcp.sentry.dev/mcp" }
```

**Cloudflare** — управление Workers/KV/R2/D1 на естественном языке. Полезно, если деплоите туда.
- Регистрация: аккаунт Cloudflare + API-токен из dashboard.
```json
"cloudflare": {
  "command": "cmd",
  "args": ["/c", "npx", "-y", "@cloudflare/mcp-server-cloudflare"]
}
```
(при первом запуске попросит авторизацию через браузер)

**Stripe** — работа с платежами, подписками, возвратами прямо из агента. Нужен только если реально обрабатываете платежи.
- Регистрация: https://stripe.com → Developers → API keys
```json
"stripe": {
  "command": "cmd",
  "args": ["/c", "npx", "-y", "@stripe/mcp"],
  "env": { "STRIPE_API_KEY": "sk_ваш_ключ" }
}
```

### 🗄️ Базы данных (если понадобятся в будущем)

Сейчас не используете БД, поэтому не подключаю. Если понадобится:
- **Supabase** — у вас уже стоит плагин в Cursor (`plugin-supabase-supabase`), просто нужно пройти авторизацию одной кнопкой в настройках MCP.
- Для чистого Postgres/SQLite — не используйте архивные `@modelcontextprotocol/server-postgres`/`server-sqlite` (deprecated, есть известные уязвимости). Актуальная альтернатива — `@executeautomation/database-server` (поддерживает SQLite/Postgres/MySQL в одном сервере) или **Postgres MCP Pro** (`crystaldba/postgres-mcp`) с настоящей read-only защитой.
